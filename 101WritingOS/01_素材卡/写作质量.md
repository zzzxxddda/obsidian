素材类型: 对话
---

```
写作质量 = 认知深度 × 表达能力 × 素材密度
```

或者说：

```
认知决定上限表达决定下限
```

举个例子。

同样看到一个现象：

```
年轻人越来越不想上班
```

A的认知：

```
因为年轻人懒
```

B的认知：

```
因为收入增长无法覆盖生活成本增长
```

C的认知：

```
工业时代的工作观与知识时代的价值观发生冲突
```

三个人的表达能力一样。

写出来的文章层次会完全不同。

所以：

> 写作竞争的核心，确实是认知竞争。

但还要补一句：

> 认知不是知道更多，而是看见更深层的因果关系。
# 2. 什么叫认知提升？

很多人理解成：

```
读更多书学更多知识
```

其实不准确。

认知提升更像：

```
现象↓原因↓机制↓本质
```

例如：

看到：

```
很多人工作很努力
```

这是现象。

---

进一步：

```
为什么有人成长快？
```

这是原因。

---

再进一步：

```
成长来自反馈而不是投入时间
```

这是机制。

---

再进一步：

```
任何复杂系统都依赖反馈闭环进化
```

这是本质。

---

认知升级实际上是：

```
看到更多层看到更深层看到更多连接
```
