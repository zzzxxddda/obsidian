| 爱的语言      | 你想表达的具体潜台词                                              |
| --------- | ------------------------------------------------------- |
| **肯定的言词** | “长期相处最容易丧失的是赞美。我想提醒自己，不要因为熟了就不说请、谢谢、你真棒。**我想夸到他心坎里去。**” |
| **精心的时刻** | “陪伴不是各刷手机。我想创造**注意力100%在对方身上**的时刻，哪怕只有15分钟，也能对抗长久的倦怠。”  |
| **接受礼物**  | “礼物不贵，是**时间的信物**。我想让他知道，我在平时也在想着他，这就是长期关系的仪式感。”         |
| **服务的行动** | “**爱是动词**。不要问‘你要不要我帮你’，而是直接观察他的疲惫，然后动手做掉那件让他烦心的小事。”     |
| **身体的接触** | “长期伴侣容易变成室友。我想保有那种**非性的、亲昵的肢体习惯**（捏捏后颈、拍拍背），这是关系的体温计。”  |
