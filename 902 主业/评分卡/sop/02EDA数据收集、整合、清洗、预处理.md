数据收集与整合
├─ 确定数据来源（特征体系）
│   ├─ 客户申请信息
│   ├─ 征信报告信息
│   ├─ 内部业务数据
│   └─ 三方外部数据
├─ 明确数据时间窗口
│   └─ 所有特征提取限定在观察期内
├─ 数据关联与合并
│   ├─ 以客户ID为主键关联多表
│   ├─ 粒度统一（聚合为客户级特征）
│   └─ 处理一对多关系（构造均值、最大值、计数等）
├─ 构造建模宽表
│   ├─ 行：客户唯一标识
│   ├─ 列：各维度特征 + 目标变量
│   └─ 记录观察期/表现期元数据
└─ 数据质量初步检查
    ├─ 缺失率统计与原因记录
    ├─ 变量分布观察与异常识别
    ├─ 时间字段一致性校验
    └─ 输出标准化数据表及数据字典
数据清洗与预处理
├─ 缺失值处理
│   ├─ 统计各变量缺失率
│   ├─ 区分缺失原因（系统缺失 vs 非命中）
│   ├─ 高缺失率变量剔除
│   └─ 填补策略
│       ├─ 数值型：均值/中位数/分箱特殊值
│       ├─ 类别型：众数/单独归为“缺失”一类
│       └─ 基于业务逻辑的特殊填补
├─ 异常值处理
│   ├─ 异常识别方法
│   │   ├─ 业务规则（如年龄>100）
│   │   ├─ 统计方法（IQR、Z-score）
│   │   └─ 模型方法（孤立森林，视需要）
│   └─ 处理方式
│       ├─ 盖帽法（设定上下限截断）
│       ├─ 分箱合并
│       ├─ 视为缺失再填补
│       └─ 剔除极端样本（审慎使用）
├─ 常量/单一值变量处理
│   ├─ 识别方差为零或唯一值占比过高（如>95%）的特征
│   └─ 直接剔除（无区分能力）
├─ 多重共线性初步筛查（可选）
│   ├─ 计算变量间相关系数
│   └─ 标记高度相关组，为后续筛选做参考
├─ 数据一致性与逻辑校验
│   ├─ 日期逻辑（无未来日期、观察期≤表现期）
│   ├─ 类别一致性（无非法编码）
│   └─ 交叉字段逻辑（如收入≥负债）
└─ 样本排除
    ├─ 排除观察期内无任何活动的样本
    ├─ 排除表现期内未形成最终标签的样本
    └─ 排除特殊样本（欺诈、政策干预等）
