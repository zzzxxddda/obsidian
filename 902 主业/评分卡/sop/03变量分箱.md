变量分箱（Binning）
├─ 分箱目的
│   ├─ 将连续变量离散化，类别变量合并
│   ├─ 捕捉非线性关系，提升模型稳定性
│   └─ 为WOE编码与评分卡构建做准备
├─ 分箱前准备
│   ├─ 区分变量类型（连续型/类别型）
│   └─ 确定分箱后最低样本量要求（每箱≥总样本5%或固定数量）
├─ 分箱方法
│   ├─ 无监督分箱
│   │   ├─ 等频分箱（每箱样本数相近）
│   │   ├─ 等距分箱（按数值区间等宽划分）
│   │   └─ 自定义分箱（基于业务经验分段）
│   └─ 有监督分箱（利用目标变量）
│       ├─ 卡方分箱（Chi-Merge，合并区分力相近的相邻组）
│       ├─ 决策树分箱（单变量决策树寻找最优分割点）
│       └─ 最优IV分箱（最大化各箱IV总和）
├─ 分箱评估与调整
│   ├─ 单调性要求：分箱后坏账率（或WOE）应呈单调递增或递减趋势
│   ├─ 业务合理性：分界点需符合业务认知（如年龄25、35、45分段）
│   ├─ 样本充足性：每箱好/坏样本均不少于设定阈值
│   └─ 异常合并：首尾箱若样本过少可合并或盖帽处理
└─ 分箱结果输出(交付物2)
    ├─ 各变量分箱区间定义
    ├─ 每箱样本数、好/坏分布、坏账率
    └─ 作为下一步WOE编码的输入
