评分卡实现与评估流程
├─► 1. 评分卡实现
│   ├─ 1.1 评分卡刻度
│   │     设定基准分、PDO，计算评分转换因子
│   ├─ 1.2 变量score的明细表
│   │     生成各变量分箱对应的分数表（评分卡表）
│   ├─ 1.3 变量score转换
│   │     根据评分卡表将样本原始特征转换为各变量得分，并求和得到总分
│   ├─ 1.4 得分明细表
│   │     汇总样本ID、各变量得分、总分及真实好/坏标签
│   ├─ 1.5 评分分布图(交付物4)
│   │     绘制总分的分布直方图或密度图
│   └─ 1.6 计算衡量指标并生成评分阈值表(交付物5)
│          输出各分数区间的通过率、坏账率、累计指标等决策表
└─► 2. 评分卡评估
    ├─ 2.1 区分度与排序能力评估
    │   ├─ 2.1.1 好坏用户得分分布图
    │   ├─ 2.1.2 绘制评分卡的KS曲线
    │   ├─ 2.1.3 PR曲线
    │   └─ 2.1.4 绘制提升图和洛伦兹曲线
    └─ 2.2 设定cutoff点
          结合业务目标（通过率/坏账率）确定分数阈值
