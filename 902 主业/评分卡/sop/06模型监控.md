模型监控
├─ 监控目的
│   ├─ 保障模型持续有效运行
│   ├─ 及时发现模型衰减与偏移
│   └─ 支持模型迭代决策
├─ 监控维度
│   ├─ 特征变量监控（前端）
│   │   ├─ 变量稳定性 PSI/CSI
│   │   ├─ 缺失率与异常值变化
│   │   ├─ 变量分布偏移监测
│   │   └─ 新特征有效性监测（若新增）
│   ├─ 模型表现监控（后端）
│   │   ├─ 区分能力指标
│   │   │   ├─ KS 值变化
│   │   │   ├─ AUC/Gini 变化
│   │   │   └─ 洛伦兹曲线/提升图对比
│   │   ├─ 校准与排序性
│   │   │   ├─ 校准曲线（预测概率 vs 实际坏账率）
│   │   │   └─ 分数段坏账率单调性检验
│   │   └─ 分数稳定性
│   │       └─ 分数分布 PSI
│   └─ 业务效果监控
│       ├─ 通过率变化
│       ├─ 坏账率变化
│       ├─ 分数分布与平均分变化
│       └─ 不同分数段客群迁移分析
├─ 核心监控指标说明
│   ├─ PSI（群体稳定性指数）
│   │   ├─ 定义：衡量实际与预期样本分数分布差异
│   │   ├─ 计算：∑(实际占比 - 预期占比) × ln(实际占比 / 预期占比)
│   │   └─ 阈值：<0.1 稳定；0.1~0.25 需关注；>0.25 显著偏移
│   ├─ CSI（特征稳定性指数）
│   │   ├─ 定义：针对单个变量的分布偏移度量
│   │   └─ 用途：定位导致模型偏移的关键变量
│   ├─ KS
│   │   ├─ 下降幅度监测（如较开发时下降>0.05 预警）
│   │   └─ 持续低于业务最低要求（如<0.25）则触发重构
│   └─ AUC
│       ├─ 与开发样本、时间外样本对比
│       └─ 长期下降趋势判断模型衰减
├─ 监控频率与实施
│   ├─ 日度监控：业务指标（通过率、平均分、分数分布概况）
│   ├─ 周度/月度监控：变量 PSI/CSI、分数分布 PSI
│   ├─ 季度/半年度监控：区分度指标（需充足表现期标签）
│   └─ 事件驱动监控：政策调整、客群变化、系统切换后即时评估
├─ 预警与触发机制
│   ├─ 设定各指标预警线与严重线
│   ├─ 自动报警通知（邮件、企微等）
│   └─ 触发诊断分析流程
└─ 监控报告与迭代
    ├─ 定期监控报表（可视化仪表盘）
    ├─ 异常归因分析与改进建议
    └─ 模型重训练或重构决策建议
