## 🧠 核心概念：Decoder-only 架构

### 1. 知识定位 (Semantic Network)

- **核心定义**：一种去掉了跨注意力层（Cross-Attention）和编码器，仅通过**掩码自注意力（Masked Self-Attention）**进行自回归生成的架构。
    
- **知识坐标**：它是 Transformer 的变体。
    
    - **上位概念**：生成式预训练 Transformer (GPT)。
        
    - **平行概念**：Encoder-only (BERT)、Encoder-Decoder (T5)。
        
    - **区别在于**：Encoder 是为了“理解”，Encoder-Decoder 是为了“转换”，而 Decoder-only 是为了“**延续**”。
        

### 2. 深度理解 (Concept & Logic)

- **底层原理**：**统一任务为“概率接龙”**。
    
    在 Decoder-only 看来，无论是翻译、问答还是推导，本质都是给出一串字符，预测下一个字符。去掉 Encoder 可以减少参数间的通讯开销，让模型更易于扩展（Scaling Up）。
    
- **关键特征**：
    
    1. **因果掩码 (Causal Masking)**：模型在看第 $n$ 个词时，被强制“打码”看不见第 $n+1$ 个词。
        
    2. **统一空间**：输入（Prompt）和输出（Completion）在同一个特征空间内处理，没有跨层的信息转换损失。
        
    3. **极强的零样本能力**：由于一直在练习“接龙”，它学会了从上下文的模式中直接推理。
        

### 3. 执行指南 (Procedural Steps)

> **触发场景**：构建对话机器人、代码助手、创意写作等需要“涌现”能力的通用大模型。

1. **Step 1：输入编码 (Prompt Embedding)**
    
    将你的指令加上位置信息，输入到模型。
    
2. **Step 2：掩码计算 (Masking)**
    
    在多头注意力计算中，应用上三角矩阵掩码。
    
    $$Attention(Q, K, V) = \text{Softmax}\left(\frac{QK^T + M}{\sqrt{d_k}}\right)V$$
    
    其中 $M$ 在非法位置为 $-\infty$，确保未来信息权重为 0。
    
3. **Step 3：自回归迭代 (Auto-regressive Iteration)**
    
    预测出词 A 后，把 A 放回输入序列的末尾，重新输入模型预测词 B，循环往复。
    
4. **Step 4：KV Cache 优化 (关键工程步骤)**
    
    为了不重复计算前面已经算过的 $K$ 和 $V$，将它们缓存起来，每次只算新加入那个词的特征。
    

- **操作要点**：**因果律（Causality）**。Decoder-only 的核心在于它只能“向后看”，不能“向后看”。
    

### 4. 视觉锚点 (Dual Coding)

- **视觉比喻**：**“单向单面镜隧道”**。
    
    想象一条隧道，墙壁全是单面镜。你在往前走时，可以透过镜子看到身后走过的所有路（历史信息），但由于镜子的物理特性，你永远看不见前面还没走到的路（未来信息）。你每走一步，就根据身后的风景决定脚下的这一步怎么踏。
    
- **逻辑结构图**：
    
    Plaintext
    
    ```
    [ 你的问题 (Prompt) ]
            ↓
    +-----------------------+
    | Decoder Block x N     |
    |  - Masked Multi-Head  | <--- 关键：只能看左边
    |  - Add & Norm         |
    |  - Feed Forward       |
    +-----------------------+
            ↓
    [ 预测下一个词 ] ──┐
            ↑          │
            └──────────┘ (循环回填)
    ```
    

### 5. 避坑与检测 (Metacognition)

- **警惕陷阱**：
    
    - **“为什么 BERT（Encoder）不行？”**：Encoder 是双向的，它在预测时会“偷看”上下文。对于生成任务来说，如果模型训练时习惯了看全貌，它在预测未来的词时就会变得非常笨拙。
        
    - **KV Cache 的成本**：虽然计算变快了，但 KV Cache 会吞噬大量显存，这是大模型长文本对话变贵的直接原因。
        
- **自测清单**：
    
    1. 在生成过程中，第 100 个词的计算能用到第 1 个词的信息吗？
        
    2. 为什么 GPT 系列坚持用 Decoder-only 而不是效果看似更均衡的 Encoder-Decoder？（提示：参数规模化带来的“涌现”效应）。
