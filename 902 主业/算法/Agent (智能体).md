## 🧠 核心概念：AI Agent (智能体)

### 1. 知识定位 (Semantic Network)

- **核心定义**：一种能够感知环境、进行自主决策、并调用工具来执行任务以达成特定目标的计算系统。
    
- **知识坐标**：它是从 **“生成式 AI”** 向 **“交互式/行动式 AI”** 的跨越。
    
    - **公式表达**：$Agent = LLM + 规划 + 记忆 + 工具使用$。
        
    - **区别在于**：LLM 只是“问答机”（你推一下它动一下），Agent 是“目标执行者”（你给目标，它自己拆解并跑完）。
        

### 2. 深度理解 (Concept & Logic)

- **底层原理**：**认知循环（Cognitive Loop）**。
    
    Agent 的核心逻辑不再是简单的“输入-输出”，而是 **“感知 (Perceive) -> 思考 (Think) -> 行动 (Act) -> 观察 (Observe)”** 的闭环过程。
    
- **关键组件**：
    
    1. **规划 (Planning)**：模型将复杂目标拆解为子任务（如 Chain of Thought 或 Tree of Thoughts）。
        
    2. **记忆 (Memory)**：包括短期记忆（上下文内容）和长期记忆（通过 RAG 检索到的经验）。
        
    3. **工具使用 (Tool Use)**：模型知道什么时候该调用搜索插件、计算器或运行一段 Python 代码。
        

### 3. 执行指南 (Procedural Steps)

> **触发场景**：当你需要 AI 替你完成一个复杂任务（如：调研某公司财报并写一份对比分析报告）时。

1. **Step 1：目标设定 (Goal Definition)**
    
    用户输入一个宽泛的目标。Agent 通过 Prompt 框架（如 ReAct 模式）理解任务。
    
2. **Step 2：任务拆解 (Task Decomposition)**
    
    Agent 思考：“要完成这个，我需要先搜集 A，再计算 B，最后汇总成 C。”
    
3. **Step 3：环境交互 (Environmental Action)**
    
    Agent 调用 API（如搜索网页）。它获得反馈结果，并观察这些结果是否满足需求。
    
4. **Step 4：迭代修正 (Reflection & Iteration)**
    
    如果结果不对，它会自我反思：“搜索结果没提到利润率，我得换个关键词再试一次。”直到达成目标。
    

- **操作要点**：**“反思机制 (Reflection)”** 是 Agent 区别于普通脚本的关键，它具备纠错能力。
    

### 4. 视觉锚点 (Dual Coding)

- **视觉比喻**：**“从‘词典’到‘职场新入职员工’的转变”**。
    
    - **LLM**：像是一本会说话的词典。你查它，它告诉你定义，然后就停在那了。
        
    - **Agent**：像是一个新来的实习生。你跟他说：“帮我订一张去上海的机票。”他会去查余票（工具）、问你的预算（交互）、看你的行程表（记忆），最后把结果发到你的邮箱，并告诉你：“订好了，顺便帮你叫了送机车。”
        
- **逻辑结构图**：
    
    Plaintext
    
    ```
    [ 用户设定目标 ]
           ↓
    +---------------------------+
    |       Agent 控制塔        |
    |  (规划 & 决策层 - LLM)    | <─── [ 反思自我纠错 ]
    +---------------------------+
      /     |      \
    [记忆] [环境感知] [工具库]
      │     │        │
    (经验) (当前状态) (API/代码)
           ↓
    [ 最终任务产出 ]
    ```
    

### 5. 避坑与检测 (Metacognition)

- **警惕陷阱**：
    
    - **无限循环（Looping）**：Agent 可能会卡在某个死循环里（如反复搜索同一个无效关键词）。这需要设置“最大迭代次数”或“人工干预点”。
        
    - **能力溢出风险**：如果给 Agent 开放了写代码并执行的权限，一定要设置“沙箱环境”，防止它误删你的硬盘。
