## 🧠 核心概念：Transformer 架构

### 1. 知识定位 (Semantic Network)

- **核心定义**：一种完全基于**注意力机制**、摒弃了循环结构（RNN）和卷积结构（CNN）的特征提取与序列生成模型。
    
- **知识坐标**：它是**基础模型 (Foundation Model)**。
    
    - **上位概念**：深度神经网络、序列对序列 (Seq2Seq) 模型。
        
    - **家族成员**：Encoder-only (BERT)、Decoder-only (GPT)、Encoder-Decoder (T5)。
        
    - **区别在于**：它通过**位置编码 (Positional Encoding)** 解决时序问题，通过**残差连接**和**层归一化**支持极深的架构。
        

### 2. 深度理解 (Concept & Logic)

- **底层原理**：解决**长距离依赖**和**并行计算**的矛盾。它认为，理解一个词的含义不需要按顺序读完之前的词，只需要建立该词与其他所有词的“加权联系”。
    
- **关键特征**：
    
    1. **非对称架构**：左边是编码器（理解输入），右边是解码器（预测输出）。
        
    2. **位置感应**：因为没有顺序，所以必须手动注入“坐标信息”。
        
    3. **自回归生成**（Decoder端）：像人类写字一样，一个词一个词地蹦，且后一个词参考前一个词。
        

### 3. 执行指南 (Procedural Steps)

> **触发场景**：从文本翻译、摘要提取到如今的图像识别、蛋白质结构预测。

1. **Step 1：特征注入 (Embedding & Positional Encoding)**
    
    将离散的符号转化为向量，并加上“位置标签”，让模型知道词与词之间的距离。
    
2. **Step 2：编码理解 (Encoder Stack)**
    
    数据通过多层编码器。每一层都通过“多头自注意力”进行全局扫描，再通过“前馈网络 (FFN)”进行非线性变换。
    
3. **Step 3：跨维度连接 (Encoder-Decoder Attention)**
    
    解码器在生成时，不仅看自己已生成的词，还要去“询问”编码器提取的源信息（这就是 $K, V$ 来自编码器，$Q$ 来自解码器的过程）。
    
4. **Step 4：概率投射 (Linear & Softmax)**
    
    将最后的向量映射到巨大的词表空间中，选出概率最大的那个词。
    

- **操作要点**：**残差连接 (Residual Connection)** 是关键。每个大模块后都有个 $X + Sublayer(X)$，这保证了信息在极深的网络中不会“干涸”（梯度消失）。
    

### 4. 视觉锚点 (Dual Coding)

- **视觉比喻**：**“现代化同声传译组”**。
    
    - **编码器（Encoder）**：是一群听众，他们听完一整段话，通过内部讨论（自注意力）整理出一份逻辑严密的“思想大纲”。
        
    - **解码器（Decoder）**：是一群翻译员，他们一边看着“思想大纲”（跨注意力），一边根据已经翻译出来的上文，预测下一个最准确的词。
        
    - **残差连接**：就像每个专家的笔记本，既记下了新讨论的结论，也保留了最初听到的原话，防止传话走样。
        
- **逻辑结构图**：
    
    Plaintext
    
    ```
    [ 输入 ] -> [ 位置编码 ]
                  ↓
    +---------------------------+
    |  Encoder 层 (x N)         |
    |  [自注意力] -> [前馈网络]  |  <-- 提取上下文特征
    +---------------------------+
                  ↓ 传递记忆 (K, V)
    +---------------------------+
    |  Decoder 层 (x N)         |
    |  [遮蔽自注意力]           |  <-- 防止提前看到答案
    |  [跨注意力] <-------------|  <-- 询问编码器
    |  [前馈网络]               |
    +---------------------------+
                  ↓
    [ 线性映射 ] -> [ Softmax ] -> [ 输出单词 ]
    ```
    

### 5. 避坑与检测 (Metacognition)

- **警惕陷阱**：
    
    - **掩码（Masking）的必要性**：在 Decoder 中，如果不把未来的词挡住（Mask），模型就会在训练时“作弊”直接看答案，导致预测时失效。
        
    - **Feed-Forward 层的作用**：很多人只记得 Attention，但 FFN 占据了模型近 2/3 的计算量，它是负责提供非线性“知识存储”的关键。
        
- **自测清单**：
    
    1. 为什么 Transformer 能够取代 RNN 处理长文本？（提示：路径长度 $O(1)$ vs $O(n)$）。
        
    2. 如果去掉位置编码，Transformer 会变成一个什么样的模型？（提示：词袋模型）。
