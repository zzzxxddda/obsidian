工作

	自己在换工作的时候会想：换工作的流程是什么？-为什么要换工作？生存、自我实现-为什么要自我实现？
	发现每次都会卡住
	为什么每次都会卡住？
	对于这个实际落地的问题一直在抽象层面思考，而不是找出实际行动中的原因。抽象是为了找方向，具体是为了行动。
```
                  抽象
                   ↑
          为什么值得做？
          我真正重视什么？
                   │
                   │
 事实 ───────► 当前问题 ◄────── 替代解释
                   │
                   │
          怎么做？如何验证？
                   ↓
                  具体
```
	什么时候使用抽象的思考？什么时候使用具体的思考逻辑考？在决策的时候才不会落入死胡同？双向穿梭的思维杠杆：
```
       【形而上 / 抽象】 (顶层定位、找方向、建立模型)
            ▲               │
            │ 归纳 (抽象化)  │ 演绎 (具体化)
            │               ▼
       【形而下 / 具体】 (底层执行、找事实、产生结果)
```

	螺旋上升的具体运行机制(形而上 / 抽象】  【形而下 / 具体】 互为基础，螺旋上升)
```
     [4. 升维后的新形而上]  ──► 指导更高阶的实践...
              ▲
              │ (归纳提炼 / 破局)
     [3. 新的形而下经验]   ◄── 重复碰壁，积累新事实
              ▲
              │ (演绎落地 / 实验)
     [2. 形而下实践]       ──► 验证假设，获取数据
              ▲
              │ (抽象建模 / 指导)
     [1. 初始形而上认知]   ──► 建立第一性原理/假设
```
