# 费曼12问题 · 个人版 v1.0

> 来源：纵横四海 EP89（邪影 Melody）。2026-11-19 首稿。
> 原始草稿见 [[2026-11-19]]；本文件是它的展开与验收版。

## 一、这个清单是什么

不是目标清单，不是 KPI，是**注意力预装**。

费曼的原始机制：把 12 个问题常驻在脑后（多数时间休眠），日常遇到的每条信息都会自动与它们做一次交叉测试；撞上的信息被留下并被精细加工，不撞的当噪音扫掉。积累到某个阈值，解法自己浮现。

判断是否有效的唯一指标：**信息是不是开始向你汇聚**。

## 二、写成一条问题的三条硬标准

| # | 标准 | 反例（不合格） | 合格写法 |
|---|---|---|---|
| 1 | **真困扰你** | 「文史哲应该读一读」 | 「为什么我一到晚上就刷手机停不下来」 |
| 2 | **指向系统改造**，不是目标达成 | 「今年读完50本书」 | 「如何建立一个让我持续阅读的生活方式」 |
| 3 | **落到一个能搭建的具体点** | 「如何提高表达能力」 | 「如何让老板听懂并采纳我的判断」 |

> 标准1的判法：连问五次为什么，问到某一层心里会「笃定」下来，那一层就是真困扰。
> 标准1b的边界：区分「我的问题」和「别人的功课」。父母的催婚焦虑是他们的功课；我如何安排自己的家庭结构是我的问题。

## 三、我的12个问题

字段说明：**真困扰**＝剥到根的那一层；**撞上来的信息**＝交叉测试时会自动被吸住的关键词；**验收**＝行为层面可观察的信号，不是完成度。

### 1 【精力OS】如何在不靠意志力的前提下，让我的注意力在下午三点仍然可用？

- **真困扰**：不是「时间不够」，是**切换成本**。996 主业、求职、A 股、学习四条线抢同一份注意力，任何一段都停不下来，切过去要花掉半小时的启动成本；到下午注意力已经被切碎，只剩惯性在跑。
- **方向**：指向默认环境（作息、仪式、单任务时段），不是「如何锻炼身体」。
- **撞上来的信息**：认知负荷、注意力残留、单任务切换成本、深度工作、精力管理、番茄钟的失效场景、16+8 断食与睡眠对注意力的影响。
- **验收**：连续两周下午三点仍能进入一段 90 分钟的深度工作；周总结里「今天被切碎几次」能给出数字。
- **线索来源**：11-03 日记「找工作想太多做太少」；11-05「国银 POC 干得有意思甚至忘记时间」。

### 2 【情绪启动OS】在什么都不想做的日子里，我靠什么机制自动回到正轨？

- **真困扰**：不是懒，是**启动回路缺失**。状态差时没有一条预设的、最小成本的回到轨道的路径，于是要么硬扛（消耗意志力），要么彻底塌掉。
- **方向**：要的是机制 + 触发条件，不是「如何自律」。
- **撞上来的信息**：WOOP、心理对比、习惯回路（暗示-惯常行为-奖赏）、最小可行行动、拖延的两类根因（任务厌恶 vs 情绪回避）、破立行、SGA 的「阻力是信号不是障碍」。
- **验收**：坏掉的连续天数从统计上看是下降的；且不依赖当天心情。
- **线索来源**：11-19 草稿「压力管理 OS：在不理智的时候如何自动走回正轨」。

### 3 【第二身份OS】如何在 996 主业之外，构建一个不靠加班也能持续推进的「风控反欺诈 + AI 数据」作品管线？

- **真困扰**：不是「没时间做副业」，是**没有一条不需要连续大块时间也能推进的路径**。996 挤掉的是整块的深度时段，而我做的事（作品、对话、表达）恰好最需要整块时间，于是永远排不上。
- **方向**：要的是「低维护成本、碎片可推进」的系统设计，不是「如何利用业余时间」。
- **撞上来的信息**：认知负荷的「分割复杂」、WOOP、微型习惯（每天30分钟产出一个可展示单元）、李笑来「每周只做一件事」、复利与最小闭环、作品集结构化叙事。
- **验收**：每周至少产出一个可对外展示的单元（一个模型/一篇笔记/一段讲解）；三个月后有 3 个以上可投递案例。
- **线索来源**：求职执行期（2026-11-02 起三个月）主线「数据开发底座 + AI 技能」。

### 4 【能力底座OS】我的核心竞争力应该建在哪个可迁移的底座上——数据开发、AI 大模型，还是行业知识？我如何用可验证的作品在 12 个月内证伪？

- **真困扰**：不是「该学哪个技术」，是**押注成本与不可证伪**。每次选择都靠感觉和叙事，选完就进入沉没成本，越陷越深，无法比较。
- **方向**：要「验证系统」，不是学习计划。
- **撞上来的信息**：巴菲特的能力圈、转换成本与迁移性、可迁移技能 vs 行业专用技能、技能定价模型、Options/Barbell 策略、决策树与期权思维、「先做后想」的验证顺序。
- **验收**：12 个月内至少一次「因为验证结果而改变押注」；每个候选底座都有可证伪的作品指标。
- **线索来源**：`104_Item/02 职业设计/职业策略.md` 第 2 问（两人毕业 7 年工资差一倍）；四条选项的取舍。

### 5 【决策OS】当四条路当下都无法用现有信息判断优劣时，我如何建立一个能做不可逆决策的判断系统？

- **真困扰**：不是「选不出来」，是**没有自己的判断器**，只能靠外界的评价、朋友的意见、机会窗口的紧迫感来倒逼，而这三样都会骗人。
- **方向**：要判断系统（怎么判断 + 何时必须决定），不是求一个答案。
- **撞上来的信息**：Cynefin 框架、贝叶斯决策与先验、决策树、可逆性/不可逆性判断、期权思维、赌徒与凯利公式、贝叶斯思维陷阱、罗盘与地图。
- **验收**：每次重大决策都能写出「我在赌什么、输赢条件、什么时候认输」；且事前写，事后对账。
- **线索来源**：`102_问题/假设生成与验证.md`；求职四选项困境。

### 6 【输入OS】如何让每周读到的、学到的东西自动进入产出，而不是停在收藏夹？

- **真困扰**：不是「学得不够多」，是**输入与输出之间没有管道**。`101_my_wiki` 里已经有可观的 wiki 数量，但它们停在 wiki 层，没有变成能被用的判断或作品。
- **方向**：要管道（输入 → 加工 → 输出的固定通道），不是读书方法。
- **撞上来的信息**：费曼学习法、卡片盒笔记、PARA、间隔重复、加工深度、汤质「管理问题不管理答案」、知识工作流与第二大脑、卡片化与可检索性。
- **验收**：每周至少一条 wiki 被改写成一个可用的产出（一个判断 / 一段话 / 一次决策依据）；每条 wiki 至少挂在一个真实问题下。
- **线索来源**：`102_问题/模糊的困扰"学不进、记不住".md`；汤质《认真学刁习》《高手的黑箱》。

### 7 【表达OS】如何把「想清楚」变成「讲清楚」——具体到向老板、向客户、向陌生人交付我的判断？

- **真困扰**：不是「表达能力差」，是**没有按对象切换表达策略的习惯**。同一套讲法对所有人，对上是抓不到重点，对外是显得自说自话，于是判断传不出去，价值打折。
- **方向**：要「面向不同对象的翻译机制」，不是「如何练习表达」。
- **撞上来的信息**：图尔敏论证模型、SCQA、金字塔原理、结构化表达、汤质「自我设问」、读者本位与作者本位的设问交汇、类比解释的力量。
- **验收**：三个月内至少三次「因表达方式改变而改变了结果」（说服、争取到机会、避免了一次误解）；有可复用的表达骨架 1–2 套。
- **线索来源**：11-19 草稿第 7 条「表达」。

### 8 【人机协同OS】如何把 AI 从「工具」变成「常驻的外部大脑」，在我判断不清时能被自动调用？

- **真困扰**：不是「AI 用得不够多」，是**它只在被我想起来时才是外挂**，且每次调用都要重新交代上下文——所以它在我最需要（判断不清）的时候反而最不省力。
- **方向**：要「常驻调用机制」，不是工具清单。
- **撞上来的信息**：上下文工程、记忆架构、认知卸载、扩展心智理论、agent 与工作流、提示词作为「注意力符号」、AI 作为思考伙伴而非搜索引擎。
- **验收**：有一个长期驻留的上下文/记忆载体（人物、项目、问题），任何时候能一句话调出「我们之前在 X 上的结论」。
- **线索来源**：11-11 日记「上下文信息对于给出个性化的回复十分重要」；11-19 草稿「人机协同 OS」。

### 9 【人际链接OS】如何建立一个低成本、可持续、跨圈层的固定聚会机制，让我在青岛持续遇到有意思的人？

- **真困扰**：不是「朋友少」，是**没有稳定机制**，靠临时起意和熟人介绍；人一挪活、换了城市，原有关系网断了且没有新建的入口。
- **方向**：要「固定时间 + 固定成本 + 参与者可预期的滚动机制」，不是「去参加更多活动」。
- **撞上来的信息**：happy hour 机制、弱连接的力量、邓巴数、三度分隔、重复曝光效应、社群运营的最小单元、「把人聚在一起，碰撞自己发生」（Echo Nest）。
- **验收**：每月至少一次固定聚会；一年后认识的人里，有 3–5 个能称为「能打电话求助的人」。
- **线索来源**：11-19 草稿第 3 条「happy-hour OS」；「人挪活」这颗种子。

### 10 【交易OS】如何把交易变成一份有固定流程、可复盘的工作，而不是情绪化的赌局？

- **真困扰**：不是「怎么赚更多」，是**我的持仓决策受情绪和叙事驱动，事后无法归因**，所以重复犯同一类错，账面盈利掩盖了方法失效。
- **方向**：要流程 + 归因 + 复盘管道，不是选股技巧。
- **撞上来的信息**：期望值与凯利、决策日志、事前预承诺、过程指标 vs 结果指标、损失厌恶与处置效应、系统化 vs 离散交易的差别、幸存者偏差。
- **验收**：每一笔交易在开仓前有书面依据（题材/模式/财务/量/空间/止损）；月度复盘能区分「决策错误」与「运气」。
- **线索来源**：`104_Item/01 投资框架/投资策略.md`；11-19 草稿「交易 OS」。

### 11 【第三收入OS】如何构建一条不占用白天注意力、但能在一年内跑通最小闭环的第三收入管线？

- **真困扰**：不是「想赚快钱」，是**结构冲突**——主业需要我全神贯注，任何需要白天响应的副业都会吃掉切换成本；同时我又确实需要一条不依赖职场的收入线来获得议价权。
- **方向**：要「睡后收入」的机制（可积累、可复制、不占注意力），不是「做点什么副业」。
- **撞上的信息**：复利与飞轮、睡后收入结构、边际成本递减、个人产品化、内容资产的复利、铁人三项 vs 全职。
- **验收**：一年内至少一条收入线做到「当月投入时间 < 产出的现金与影响力」；有一份可重复的 SOP。
- **线索来源**：11-19 草稿第 5 条。

### 12 【身份OS】在「我想成为的人」之外，我如何确认这条路是自己选的，而不是被规训、被舒适区慢慢替换掉的？

- **真困扰**：不是「要不要坚持」，是**无法分辨「我在选择」和「我在被安排」**。外部系统（原生家庭的稳定叙事、职场的评价体系、消费社会的欲望结构）随时在改写我的目标，而我直到几年后才发现方向早就不是我定的。
- **方向**：要「审视机制 + 定期校验」，不是价值观宣言。
- **撞上的信息**：费曼12问题的自指问题、社会时钟与婚恋市场物化、荣格阴影整合、区分「我的课题」与「别人的课题」、被规训与野性（wilderness）、定期的人生审计。
- **验收**：每年做一次「哪些东西是别人塞给我的」的清单；至少能说清一条「即使没有外部收益我也愿意走」的理由。
- **线索来源**：`104_Item/02 职业设计/工作观&人生观.md`；长期问题「活着的意义」；EP89 三年后的第五个新问题。

## 五、交叉测试记录位

费曼12问题只有一个硬指标：**信息有没有开始向你汇聚**。所以每条问题需要一个「撞了几次」的计数。

| 4 | 能力底座 |  |  |
| 5 | 判断系统 |  |  |
| 6 | 输入→产出管道 |  |  |

| 10 | 交易系统 |  |  |
| 11 | 第三收入 |  |  |
| 12 | 身份/自主 |  |  |

**每周在 909_log 周总结的 `sga--weekreview` 区块加一行**：`本周撞到：#N（撞到了什么）`。

- 一周没撞到任何一条 → 输入质量不行，或问题写错了（回看是否被三条标准筛过）。
- 同一问题连续两周以上撞到 → 它正在解冻，是当前主问题，多花时间。
- 某条三个月一次没撞 → 它已经解决，或它根本不是你的问题，考虑替换。

## 六、迭代规则

1. **半年一次体检**：读一遍 12 条，删掉已解决的，换上候选池里被反复撞到的。
2. **一年一次整体复核**：EP89 的作者三年换了 5 条，节奏大致如此。
3. **解法不写在这里**：问题解出来了，就去把对应的子系统落地（作息、环境、流程、工具），然后把那条问题标成「已解答」并写一句「答案是什么、变成了什么机制」。
4. **不设完成度**：清单不是考核表。EP89 作者三年后 5 条成功、3 条半成、2 条彻底失败——失败的两条也给出了重要信息（日语是幼年执念的残影，游戏化会让人只做有趣的事而绕过痛苦管理）。

## 七、相关

- [[sga原则]]：SEE/Grow/Action 的落地节奏，和本清单是「内容层 vs 注意力层」的关系。
- [[log原则]]：每日最小记录剂量，本清单的撞点记录需要它做数据源。
- [[问题树分解法]]：MECE 拆解是「把一个问题摊开」的工具；本清单是「决定该摊开哪几个问题」的工具。
