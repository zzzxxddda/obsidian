### 按照时间尺度划分的常见“周期”

| 周期类型        | 典型时间跨度       | 驱动因素                     |
| ----------- | ------------ | ------------------------ |
| **日内周期**    | 分钟~小时        | 开盘/收盘效应、早盘博弈、午盘流动性变化     |
| **星期效应**    | 周            | “黑色星期四”、“周五减仓”、资金周末避险    |
| **月份/旬度**   | 月            | 月末机构调仓、期权期货到期日、PMI等数据发布  |
| **季报/财报周期** | 3个月          | 季报披露前后波动加大，业绩预期炒作        |
| **年度/日历效应** | 1年           | “春季躁动”、“五穷六绝七翻身”、年末流动性紧张 |
| **宏观周期**    | 3~5年（基钦周期）   | 库存周期、货币宽松/紧缩             |
| **长波周期**    | 7~10年（朱格拉周期） | 设备投资、产能扩张与淘汰             |
