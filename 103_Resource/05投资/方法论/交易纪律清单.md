# 交易纪律清单

> 来源：2026-W32 日志实践提炼，结合《交易一致性与稳定盈利》方法论
> 更新：2026-08-10

---

## 一、总则：只做模式内的交易

1. 只有满足条件的行情能做，看不懂的逻辑不做
2. 不是结果导向——交易前问"这是我的规则吗？"，而不是"涨了错过怎么办"
3. 模式正确也可能失败，接受模式内的亏损
4. 会错过模式捕捉不到的行情，这是成本而非错误
5. 学习的目的：从随机概率变为高质量概率分布图
6. 知识可能有害、会过期、无法抵挡黑天鹅——保持敬畏

## 二、买入纪律

1. 没有符合买入逻辑的，不参与
2. 买入条件 checklist（需同时满足多个）：
   - [ ] 资金净流入
   - [ ] 量价配合
   - [ ] 形态突破（N字突破 / 双突破）
   - [ ] 盈亏比 ≥ 2:1
   - [ ] 板块/题材逻辑支撑
3. 回抽确认时不应买入（等确认完成）
4. 买入前必须列出缺点和风险（如：上方压力近、无利好、财报不佳）
5. 顺势而做，通过双突破确认趋势反弹

## 三、卖出纪律

1. 跌破支撑位先出——可能被洗下去，但纪律优先
2. 设好的止损必须执行，不犹豫
3. 买入时就必须制定卖出计划
4. 趋势交易：大止损大止盈；震荡交易：小止损小止盈
5. 不因盈亏情绪化调整仓位

## 四、看盘纪律

1. 看盘是为了确认规则，不是寻找机会
2. 固定看盘时间，用时间规则避免多巴胺刺激
3. 区分"研究"时间与"看盘"时间
4. 研究时应从题材切入（如无人驾驶第一天找未上车标的），而非盯个股波动

## 五、市场认知

1. 宽幅波动大概率会打回来——等波动率变小才做突破
2. 突破就回调，往往已经在走通道了——注意交易区间
3. 题材力量会推动背后标的，关注板块联动
4. 情绪周期打开时（如传智8板），市场有效支撑时可参与
5. 收集信息很重要——信息质量决定判断质量

## 六、战略原则（孙子兵法）

1. 选择战场，建立形势，一击必中
2. 先立于不败之地，再寻求胜机
3. 能不打就不打，打就一击命中
4. 凡事先算账，不打没有胜算的战
